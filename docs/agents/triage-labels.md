# Labels de Triage

Las skills hablan en términos de cinco roles canónicos de triage. Este archivo mapea esos roles a los strings de label reales que usa el issue tracker de este repo.

| Label en mattpocock/skills | Label en nuestro tracker | Significado                                       |
| -------------------------- | ------------------------ | ------------------------------------------------- |
| `needs-triage`             | `needs-triage`           | El mantenedor necesita evaluar este issue         |
| `needs-info`               | `needs-info`             | Esperando al reportante por más información       |
| `ready-for-agent`          | `ready-for-agent`        | Totalmente especificado, listo para un agente AFK |
| `ready-for-human`          | `ready-for-human`        | Requiere implementación humana                    |
| `wontfix`                  | `wontfix`                | No se va a accionar                               |

Cuando una skill menciona un rol (por ejemplo, "aplica el label de triage listo para AFK"), usa el string de label correspondiente de esta tabla.

Edita la columna de la derecha para que coincida con el vocabulario que realmente uses.
